Use it

Point your client at {{ server_name }}. It answers NTPv4 over both IPv4 and IPv6.

chrony — /etc/chrony/chrony.conf

server {{ server_name }} iburst

ntpd — /etc/ntp.conf

server {{ server_name }} iburst

systemd-timesyncd — /etc/systemd/timesyncd.conf

[Time]
NTP={{ server_name }}

macOS

sudo sntp -sS {{ server_name }}

Windows

w32tm /config /manualpeerlist:"{{ server_name }}" /syncfromflags:manual /update

One server is one opinion. For anything that matters, give your client three or four sources so it can outvote a liar: a public pool plus this one is a good mix.
