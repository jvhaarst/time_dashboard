Use this time server

Point your client at {{ server_name }}. It answers NTPv4 over IPv4 and IPv6{% if pool_url %}, and is part of the global NTP pool{% endif %}.

  • chrony: server {{ server_name }} iburst in /etc/chrony/chrony.conf
  • ntpd: server {{ server_name }} iburst in /etc/ntp.conf
  • systemd-timesyncd: NTP={{ server_name }} in /etc/systemd/timesyncd.conf
  • macOS: System Settings › General › Date & Time › Source, or sudo sntp -sS {{ server_name }}
  • Windows: w32tm /config /manualpeerlist:"{{ server_name }}" /syncfromflags:manual /update

One server is one opinion. For anything that matters, give your client three or four sources so it can outvote a liar.

Frequency stability (Allan deviation)

{{ adev_chart|safe }}

Overlapping Allan deviation of chronyd's frequency corrections over the last 30 days, computed from 120-second averages. The shortest τ is 120 s because that is the finest step a 30-day range query fits inside VictoriaMetrics' point budget. Falling with τ is white frequency noise being averaged away; a floor or an upturn at long τ is the oscillator's own drift.
